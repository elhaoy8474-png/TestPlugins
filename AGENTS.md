# Instructions for AI agents working in this repository

Before starting any task, read the complete [AI_PROJECT_REFERENCE_AR.md](./AI_PROJECT_REFERENCE_AR.md). It is the primary, persistent project memory.

Mandatory:
- Work in this repository and preserve the existing four providers unless the owner explicitly requests changes.
- Use mo7AmMeD64/cs-ar as the primary Arabic CloudStream source reference and mo7AmMeD64/ar_aniyomi as a secondary parsing reference.
- Only shortlist new providers when real Arabic subtitles or Arabic audio/dubbing are evidenced on actual content pages. Plugin metadata language alone is not evidence.
- Keep each provider as an independent Gradle module.
- Do not bypass login, subscriptions, DRM, paywalls, CAPTCHAs, or geographic restrictions.
- Distinguish compilation from catalog, detail, subtitles, extractor, and in-app playback tests.
- Never claim a plugin works without a real KodaStream runtime test.
- Verify repository manifests, artifact URLs, file sizes, and SHA-256 after publication.
- Update AI_PROJECT_REFERENCE_AR.md whenever repository state, provider status, bugs, or release procedure changes.
