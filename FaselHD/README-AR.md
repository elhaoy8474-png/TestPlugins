# إضافة FaselHD

إضافة عربية مستقلة لـ CloudStream للموقع `https://www.fasel-hd.co`.

## الميزات
- أقسام الأفلام والمسلسلات والأنمي.
- استخراج بطاقات الفهرسة والتفاصيل والبحث عبر نموذج الموقع.
- جمع حلقات الموسم الحالي والمواسم المرتبطة وترتيبها حسب الموسم ورقم الحلقة.
- التقاط رابط HLS الناتج من مشغّل JWPlayer عبر WebView، دون تخزين رموز المشغّل أو روابط الجلسات.

## نتائج التحقق
- صفحات الفهرسة والتفاصيل والحلقات: HTTP 200 في بيئة الاختبار.
- اختبارات parser المحلية: PASS.
- بناء CloudStream `.cs3`: PASS.
- مشغّل الموقع: أظهر خوادم Auto و1080p و720p و360p؛ روابط HLS وقائمة المقاطع أعادت HTTP 200 في اختبار المتصفح.
- البحث الآلي من بيئة الاختبار: 403/Cloudflare؛ لم يتم تجاوز التحقق.
- تثبيت وتشغيل داخل KodaStream على هاتف فعلي: NOT TESTED، ولذلك حالة الإضافة Beta.

لا تتجاوز الإضافة تسجيل الدخول أو CAPTCHA أو أي قيود وصول، ولا تُضمّن رموز تشغيل مؤقتة في المصدر.
