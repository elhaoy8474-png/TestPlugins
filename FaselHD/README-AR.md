# إضافة FaselHD

إضافة عربية مستقلة لـ CloudStream تستهدف الموقع `https://www.fasel-hd.co`.

- أقسام الأفلام والمسلسلات والأنمي.
- البحث عبر نموذج الموقع.
- تفاصيل الأفلام والمسلسلات وقائمة الحلقات الظاهرة.
- استخراج مشغل الحلقة المضمّن عبر WebViewResolver.

لا تتجاوز الإضافة صفحات التحقق أو تسجيل الدخول أو القيود التقنية للموقع.

حالة التحقق: صفحات الفهرسة والتفاصيل جرى فحصها من اتصال الاختبار. البحث واجه 403/Cloudflare في بيئة الفحص. روابط التشغيل موجودة في الصفحة لكن استخراجها لم يُثبت بعد في CloudStream. يلزم بناء CI واختبار KodaStream الفعلي.
